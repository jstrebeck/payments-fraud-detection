# dashboards

Grafana dashboards as JSON, provisioned into the existing
`kube-prometheus-stack` via a ConfigMap with the `grafana_dashboard: "1"`
label (generated by `deploy/base/dashboards-configmap.yaml`).

Planned:

| File | Panels |
|---|---|
| `payments-api.json` | request rate, error rate, latency p50/p95/p99, decision mix, scorer fallback rate |
| `fraud-model.json` | score histogram over time, live model version, decisions by version, latency by scorer, labelled precision/recall (Phase 7) |
| `training.json` | last training run status/time (from CronJob metrics), PR-AUC across registered versions (MLflow datasource or pushed metrics) |
| `drift.json` | PSI per feature, drift flag timeline, retrain events |

Export from Grafana with "Export for sharing externally" so datasource UIDs
are templated. Keep dashboard `uid`s stable so links in runbooks do not
break.
